# Sistemas Operacionais — Produtores e Consumidores

Este trabalho tem como objetivo desenvolver um sistema de comunicação entre múltiplos produtores e consumidores em C, explorando dois paradigmas de IPC no Linux: memória compartilhada com semáforos e filas de mensagens. A proposta é compreender, na prática, como coordenar processos concorrentes e sincronizar a produção e o consumo de mensagens.
